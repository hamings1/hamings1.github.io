SpikingLM: Towards Fully Spiking Language Model

Bringing language understanding to fully spiking computation.

Yu Liang, Zijian Zhou, Wenjie Wei, Shuai Wang, Honglin Cao, Ammar Belatreche, Yu Yang, Malu Zhang, Yang Yang, Haizhou Li

Read paper ↗Code ↗BibTeX

Overview

SpikingLM addresses two obstacles in deep spiking language models: inactive neurons that weaken gradients, and the loss of token competition when Softmax is removed. It combines Distribution-aware Scaling with Spike2Max to improve training and attention while retaining efficient computation.

How it works

01

Distribution-aware Scaling

Rescales linear outputs into a range that supports neuron activity and gradient propagation. The scaling parameters can be fused into the preceding linear layers for inference.

02

Spike2Max attention

Restores competition between tokens using base-2 exponentiation and max-subtraction, enabling efficient bit-shift operations.
